# Customer Churn Prediction using Machine Learning

This project was developed as part of the Lloyds Banking Group Data Science Virtual Experience Program.

## Project Components
- Data Gathering
- Exploratory Data Analysis (EDA)
- Data Cleaning & Preprocessing
- Random Forest Classification Model
- Model Evaluation

## Results
- Accuracy: 75.5%
- Confusion Matrix
- Feature Importance Analysis

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- Google Colab
